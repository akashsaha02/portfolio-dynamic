The LCP element is the hero portrait `<img alt="Portrait of Akash Saha">` (`components/hero/Hero.tsx:29-37`). LCP is late because the `hero-develop` animation keeps the image clipped (`clip-path: inset(100% 0 0 0)` from a 250 ms delay over 1.2 s, `app/globals.css:125-145`) and the browser does not record LCP until the image is painted.

- Accessibility: `color-contrast` (46 About-section `.word` spans at opacity 0.16) and `label-content-name-mismatch` (the "AS" link has `aria-label="Akash Saha, back to top"`, which does not contain its visible text "AS", `components/Nav.tsx:18-24`).

- Requests that matter: the Mona Sans woff2 is **96 KB** (variable `wdth` axis) and is preloaded. Portrait `w=1080` 32 KB, `abroadly.webp` 25 KB, `abroadly-phone` 15 KB, `nook` 10 KB. Total page weight 428 KB on mobile and 445 KB on desktop.

## 5. Lessons for Folio (must not repeat)

1. **L1, JS budget.** The framework floor is already 119 KB gzipped, so 120 KB "home JS" leaves about 1 KB for the app. Either the plan clarifies that the budget means *app JS beyond the framework* (Editorial: 65.6 KB) or Folio must code-split GSAP/ScrollTrigger/Lenis out of the first load. Today they are 52 KB loaded eagerly. Raise this with the plan owner before Phase 1 is gated. (B-02)
2. **L2, never animate the LCP element's visibility.** No clip-path, opacity or filter reveal on the hero portrait (or whatever the LCP element is). A 1.7 s render delay costs the mobile LCP budget by itself. Animate the elements around it instead, and add `fetchpriority="high"` to the preload. (B-01)
3. **L3, the focus ring must be checked against every surface it can land on.** Pick it per surface, never per section: a lime ring on a lime card disappears. Do not set `border-radius` on `:focus-visible`. (B-03, B-15)
4. **L4, no text over the portrait.** Copy must not sit over the photo at any width, especially 768 and 1024 portrait, where the photo is widest relative to the copy. (B-04)
5. **L5, reveals must not leave text half-visible.** Use clipped `yPercent` reveals that finish at full opacity, not scrubbed opacity that holds at 0.16. Reduced motion must also remove *delays*: set `animation: none`/`animation-delay: 0s`, not only a short duration. (B-05, B-08)
6. **L6, 44 px targets with 8 px gaps in the top bar and menu.** Editorial's nav is 40 px with 4 px gaps everywhere. Folio's burger and menu items need measuring at 320. (B-06, B-13)
7. **L7, Lenis off on touch and mounted in the template**, gated on `(hover: hover) and (pointer: fine)` as well as reduced motion. Restore any global GSAP settings on cleanup. (B-07, B-18)
8. **L8, landscape phones need their own hero check.** `min-h` in rem pushed the CTAs off a 360 px tall screen. Use `svh` with a clamp so the CTA stays above the fold at 740×360. (B-09)
9. **L9, the phone menu lists every section** (Editorial hides Experience below 640 px), and labels must fit at 320. (B-10, B-11, B-12)
10. **L10, one easing family**, transform/opacity/clip-path only (no `filter` tweens), and an intro under 1.6 s. (B-17)
11. **L11, decorative lime script on paper is 1:1.** If it returns, keep it on ink. (B-16)
12. **L12, configure `images.qualities` and `deviceSizes` from day one, and ship an OG image** for each page if `summary_large_image` is declared. (B-19, B-20)
13. **L13, Mona Sans with the `wdth` axis is a 96 KB font preload.** Subset it or check whether a static condensed cut is lighter.

## 6. How to re-run this exactly

Tools are installed in a throwaway folder outside the repo; nothing is added to `package.json`. The scripts are saved in `docs/qa/baseline/tools/`.

```bash
# 0. Gates (repo root)
npm run lint
npx tsc --noEmit
npx next build

# 1. Serve the production build on a port no other agent uses
npx next start -p 3300          # run in background; stop when done

# 2. Throwaway tool folder (any temp dir, NOT inside the repo)
T=<temp>/qa-tools && mkdir -p "$T" && cp docs/qa/baseline/tools/*.js "$T" && cd "$T"
npm init -y && npm i playwright@1.64.0 @axe-core/playwright@4.13.0 lighthouse@13.5.0 pngjs@7.0.0
npx playwright install chromium

# 3. Screenshots + overflow + tap targets + lime contrast + keyboard pass
#    (writes PNGs to <out> and audit-results.json next to it)
node audit.js http://localhost:3300/ <repo>/docs/qa/<phase>/screens
node shrink.js <repo>/docs/qa/<phase>/screens <repo>/node_modules/sharp   # full-page PNG -> JPEG

# 4. axe (phone 360x740 + desktop 1280x800, on load and after scroll),
#    reduced-motion timing probe, focus-under-nav probe
node axe.js http://localhost:3300/ <repo>/docs/qa/<phase>/axe-results.json

# 5. Hero intro text vs portrait pixels (tablet contrast)
node introbg.js http://localhost:3300/

# 6. Lighthouse, 3 runs each (system Chrome; or set CHROME_PATH to Playwright's chromium)
export CHROME_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe"
for i in 1 2 3; do
  npx lighthouse http://localhost:3300/ --form-factor=mobile --output=json --output-path=lh/mobile-$i.json --chrome-flags="--headless=new" --quiet
  npx lighthouse http://localhost:3300/ --preset=desktop     --output=json --output-path=lh/desktop-$i.json --chrome-flags="--headless=new" --quiet
done
node lhsum.js lh <repo>/docs/qa/<phase>/lighthouse-summary.json   # medians + failing audits

# 7. JS shipped for a route (every <script src> in the HTML, gzip -9 from .next/static)
node jssize.js http://localhost:3300/ <repo>

# 8. Secrets in client bundles
grep -rlE "NEXT_PUBLIC_|MONGODB|PAYLOAD_SECRET|API_KEY" .next/static
```

Environment for this run: Windows 11, Node 22.21.0, npm 11.6.2, Chrome 154 (Lighthouse), Playwright Chromium headless shell 1248.
